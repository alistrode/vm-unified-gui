# 容器外独立标准桌面（开发中）

仅用于现有 `Ubuntu-MultiContainer-GUI` 虚拟机，不操作其他虚拟机，不自动关机。

模式一以实际完整桌面功能验收，不以外观或截图相似作为通过条件。使用 Ubuntu 24.04 上原生 Xfce 4.18，为三个应用容器在容器外建立三个独立桌面会话（:101、:102、:103），各自有桌面、面板、窗口管理、工作区、设置和会话总线。统一入口同时显示三个完整桌面；没有自绘桌面、装饰性框架或截图替代。

三个会话共用宿主一套已安装的 Xfce/Xorg/Xpra 软件，各自运行会话进程并保存配置，不是安装三个系统或三套依赖。桌面进程及配置位于容器外、这台 Ubuntu 虚拟机内。

模式二显示原有 :100 标准桌面，尺寸 1280×800，放置来自 A/B/C 的三个真实应用窗口。参考仅为 `docs/original/final.png`。模式一各自桌面和模式二各有应用窗口：切换显示模式不会关闭后台桌面或应用，但两种模式不是同一个窗口在不同 X 服务器之间迁移，编辑器文档不会自动同步。各容器的文件系统仍是同一个。

## 依赖与边界

容器沿用现有 `unified-real-apps:24.04` 镜像、标识和挂载。容器内只运行应用及其必需库；图形应用仍必需 GTK/X11 等客户端库，不能描述为“零图形库”。容器内不安装或运行 Xorg、窗口管理器、面板或桌面会话。

外部运行环境（源码目录不包含第三方软件或虚拟磁盘）：

- Ubuntu 24.04.3、Python 3.12、python3-dbus、python3-gi/Gdk 3。
- Xfce 4.18、Xorg dummy、Xpra 6.5.4-r0-1、Xpra HTML5 v21、nginx、Docker Engine/Compose。
- wmctrl、xdotool、xauth、x11-xserver-utils、cvt。功能验证另使用 xclip。
- 现有 `/srv/unified/compose.yaml`、`xorg-shared.conf`、认证文件、共享目录、原显示与容器服务，以及既有镜像。

Xpra 上游：https://github.com/Xpra-org/xpra （GPL-2.0）；HTML5 客户端：https://github.com/Xpra-org/xpra-html5 （MPL-2.0）。`patch_xpra.py` 修补已识别版本的 resize-display 守卫；`patch_html5.py` 修改连接超时和就绪句柄。补丁保留原文件备份，上游软件不属于本项目自有源码。

## 既有项目安装

将本目录放入目标虚拟机，在目录中运行 `sudo bash install.sh`。安装器依赖现有项目，是部署源码，不是独立运行包。会备份原配置、创建容器外桌面配置与服务、配置 nginx，并重启项目显示服务和应用；会中断当前桌面应用，不重建容器镜像或关闭虚拟机。已有独立桌面配置会保留。

浏览器访问现有 8080 入口；B 机现有映射为本机 48080。使用原生应用菜单中的模式入口或 Super+F1/F2。原快捷键被占用时会选择空闲备用键。三个独立桌面通过同一 nginx 入口转发，附加 Xpra 端口仅监听回环地址。

## 已验证与未通过项

在真实目标 VM 中逐个验证三个独立桌面：原生应用查找器和设置打开；工作区 A 切换不影响 B/C；各自最大化和最小化；A 终端在 A 容器执行文件写入；B 编辑输入和剪贴板；C 文件管理器在 C 容器创建文件夹；模式往返保留三个桌面窗口与编辑内容。

统一浏览器入口的三个独立会话仍须完成端到端验收，音频、外设、GPU 加速及全部桌面设置尚未完整验收。当前模式二 1280×800 实机截图与原图相比有 25,831 个不同像素（2.5226%），尚未通过逐像素完全一致验收；不冻结时钟或替换截图来制造通过结果。不能把已验证项目扩展声称为“所有功能通过”。

历史设计预览、局部浏览器验证和模拟接口不构成本版本的真实目标机验收。
